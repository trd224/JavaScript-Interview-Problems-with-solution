#038 What is ViewChildren

🔹 What is ViewChildren in Angular?

🔹 One-Line Interview Answer

  • 👉 ViewChildren is a decorator used to access multiple DOM elements or child components from the parent component class in Angular.

🔹 Why Use ViewChildren?

  • Access multiple DOM elements
  • Access multiple child components
  • Loop through child components or elements

🔹 Example (Access Multiple Input Elements)

  • Template
<input #myInput type="text" value="Angular">
<input #myInput type="text" value="React">
<input #myInput type="text" value="Vue">

<button (click)="showValues()">Show</button>
  • Component
import { Component, ViewChildren, QueryList, ElementRef } from '@angular/core';

export class AppComponent {

  @ViewChildren('myInput') inputs!: QueryList<ElementRef>;

  showValues() {
    this.inputs.forEach(input => {
      console.log(input.nativeElement.value);
    });
  }

}

🔹 Example (Access Multiple Child Components)

  • Child Component
export class ChildComponent {

  greet() {
    console.log("Hello from Child");
  }

}
  • Parent Template
<app-child></app-child>
<app-child></app-child>
<app-child></app-child>

<button (click)="callChildren()">Call All</button>
  • Parent Component
import { ViewChildren, QueryList } from '@angular/core';
import { ChildComponent } from './child.component';

export class ParentComponent {

  @ViewChildren(ChildComponent) children!: QueryList<ChildComponent>;

  callChildren() {
    this.children.forEach(child => child.greet());
  }

}

🔹 When ViewChildren Works

  • 👉 Available after view initialization
ngAfterViewInit() {
  // ViewChildren is available here
}

🔹 ViewChild vs ViewChildren

ViewChild ViewChildren
Returns first matching element Returns all matching elements
Returns single object Returns QueryList
Access one child Access multiple children

🔹 Key Points

  • Used to access multiple DOM elements or child components
  • Returns a QueryList
  • Works in TypeScript (not template)
  • Available inside ngAfterViewInit()
  • Use forEach() to iterate over all items
